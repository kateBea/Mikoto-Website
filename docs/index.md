# Mikoto Engine

Mikoto is an open-source, Vulkan-based game engine written in modern C++20. It is built as an educational project for exploring graphics programming.

[Install and build](getting-started/build.md)

[View on GitHub](https://github.com/kateBea/Mikoto)

## Documentation

| Layer | What lives there |
| --- | --- |
| **Runtime** | ECS, scene graph, assets, physics, audio, scripting, and networking |
| **Renderer** | Vulkan, clustered Forward+, HDR environments, MSDF text, and Slang |
| **Editor** | ImGui, transform gizmos, infinite grid, and asset hot reload |
| **Tooling** | CMake builds, Tracy profiling, validation layers, and platform scripts |

Start with [Install & build](getting-started/build.md), or browse the sections in the navigation.

!!! note
    Mikoto is under active development. The `develop` branch is the current architecture and may change over time.
