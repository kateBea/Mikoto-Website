## Inspirations

The project draws from:

- [LearnOpenGL](https://learnopengl.com/)
- [The Cherno](https://www.youtube.com/@TheCherno)
- [Cem Yuksel](https://www.youtube.com/@cem_yuksel/videos)
- [Game Engine Architecture](https://www.gameenginebook.com/)
- [Physically Based Rendering](https://www.pbr-book.org/)
- [Sascha Willems' Vulkan examples](https://github.com/SaschaWillems/Vulkan)
- *Mastering Graphics Programming with Vulkan* by Marco Castorina and Gabriel Sassone

Mikoto is still early and evolving. Features are added progressively as new graphics programming ideas become concrete. Feedback and careful experiments are welcome.
