# Dependencies

Mikoto builds on focused open-source libraries rather than trying to own every layer of the engine.

| Area | Libraries |
| --- | --- |
| ECS | [EnTT](https://github.com/skypjack/entt) |
| Model loading | [tinygltf](https://github.com/syoyo/tinygltf), [Assimp](https://github.com/assimp/assimp) |
| Images | [stb](https://github.com/nothings/stb) |
| Physics | [Jolt Physics](https://github.com/jrouwe/JoltPhysics) |
| Audio | [miniaudio](https://github.com/mackron/miniaudio) |
| Scripting | [sol2](https://github.com/ThePhD/sol2), Lua |
| UI and gizmos | [Dear ImGui](https://github.com/ocornut/imgui), [ImGuizmo](https://github.com/CedricGuillemet/ImGuizmo) |
| Text | [msdfgen](https://github.com/Chlumsky/msdfgen) |
| Networking | [Asio](https://github.com/chriskohlhoff/asio) |
| Profiling | [Tracy](https://github.com/wolfpld/tracy) |

For the authoritative list and exact versions, use `THIRD_PARTY.md` in the engine repository.
